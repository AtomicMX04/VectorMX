# 🎬 FanPelis-desktop

Aplicación de escritorio desarrollada de forma nativa utilizando **Electron** y **Node.js**, diseñada para ofrecer una experiencia cómoda y fluida directamente desde el sistema operativo.

---

## 📥 Descarga e Instalación

Puedes descargar la versión más reciente y estable directamente desde nuestra sección oficial de lanzamientos:

👉 **[Descargar FanPelis-desktop desde los Releases](https://github.com/AtomicMX04/VectorMX/releases/tag/v1.0.0)**

### Instrucciones de uso:
1. Entra al enlace de arriba y descarga el archivo comprimido `.rar` de la última versión.
2. Descomprímelo en una carpeta de tu preferencia en tu computadora.
3. Ubica el archivo ejecutable (`.exe`) dentro de la carpeta generada y ábrelo para comenzar a usar la aplicación.

---

## 🛠️ Tecnologías Utilizadas
* **Electron** — Para el empaquetado como aplicación de escritorio nativa.
* **Node.js** — Como entorno de ejecución.
* **HTML / CSS / JavaScript** — Para la interfaz y lógica visual.
